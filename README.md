# ChicAnime

**ChicAnime** is an anime website for browsing anime titles and opening their episode pages.

🌐 **Live website:** https://mr-shankar7.github.io/ChicAnime/index.html

## How it works
- **HTML** provides the website pages and structure.
- **CSS** controls the layout and responsive styling.
- **JavaScript** powers interactive features such as searching, filtering, and page behavior.
- **Firebase** supports the project features configured to use it.
- **GitHub Pages** hosts the public website from this repository.

## Project structure
- `index.html` — main page.
- `Watch.html` and related pages — episode viewing pages and other site sections.
- `css/` — stylesheets.
- `js/` — JavaScript files.
- `manifest.json` — web app metadata.

## Update the website
1. Edit the relevant HTML, CSS, or JavaScript files.
2. Commit and push your changes to the repository.
3. GitHub Pages publishes updates from the configured publishing branch.

> **Note:** Video playback, authentication, and other Firebase-powered features depend on their configured services and security rules.
